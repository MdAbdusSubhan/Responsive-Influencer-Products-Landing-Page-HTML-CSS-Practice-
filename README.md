# Responsive Influencer Products Landing Page

A responsive e-commerce landing page built as a practice task from Programming Hero using semantic HTML and plain CSS.

## Features
- Responsive layout for mobile, tablet, and desktop
- Custom navigation bar with mobile menu
- Product grid using CSS Grid
- Clean UI based on a given design

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Font Awesome

## Purpose
This project was created to practice layout structuring and responsive design without using any CSS frameworks or JavaScript.
